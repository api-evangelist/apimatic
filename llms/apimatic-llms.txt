# APIMatic Docs

> One Source, Many Outputs. APIMatic generates SDKs, API docs, code samples, MCP servers, context plugins, and developer portals from OpenAPI specs.

Full markdown source for any page is available by appending `.md` to its URL (e.g., `https://docs.apimatic.io/getting-started/creating-your-first-portal.md`).

Full concatenated content: https://docs.apimatic.io/llms-full.txt

- [Introduction](https://docs.apimatic.io/): APIMatic is a Developer Experience platform for APIs. The APIMatic documentation gives you hands-on experience in automating SDK generation, API portals and transforming APIs.
