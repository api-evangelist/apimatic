This report compares a recurring subscription-billing integration across four provider-resource conditions. All reported runs completed the functional API task and met the tested API-contract checks. The observed differences therefore concern operational integration quality: resilience, error hygiene, configuration behavior, API-drift handling, wire coupling, and API-learning effort.
